# GEMINI.md

This file contains project-specific instructions and mandates for AI agents working on the **shopbee-ui** project.

## 🎨 UI Development Mandates

- **UI Components & Patterns**: You MUST use the 'primevue-ui-patterns' skill for all UI-related tasks. This ensures consistency with PrimeVue 4, Nuxt 4, and Tailwind CSS v4 patterns established for the Shopbee platform.
- **Component Library**: Exclusively use PrimeVue 4 components for building interfaces.
- **Styling**: Use Tailwind CSS v4 for utility-first styling, ensuring proper coordination with PrimeVue's theme presets.
- **State Management**: Prefer Nuxt 4 composables for business logic and local state management, as demonstrated in the existing 'app/composables/' directory.
